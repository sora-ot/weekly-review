# 拾周

本地周报与待办网页，使用微软雅黑。需要 Node.js 22.13 或更高版本，无需安装依赖。

## 启动

双击 `start.bat`，或在当前文件夹运行：

```sh
npm start
```

打开 http://localhost:3000。启动窗口需保持打开；按 Ctrl+C 停止。

## 功能

- 周一至周日的真实日历，使用 ISO 周数；可切换月份、年份和周。
- 周记录可指定当周日期，也可不指定；支持编辑、删除、搜索和单条文字颜色、字号。
- 周总结自动保存，也可导出当前周的 Markdown 周报。
- 所有记录总览按周显示历史记录和周总结，支持跨周搜索、年份筛选、编辑记录与跳转周报。
- 全局待办支持分钟级截止时间、逾期标识、完成、恢复、编辑与删除。
- 四款本地柔和背景、自定义图片上传、界面与内容独立字号，以及界面、标题、周报、待办分区域文字颜色；背景只应用于页面底层，周标题卡片保持固定背景。
- 左侧导航可折叠、展开，自动记住状态；手机上通过顶部按钮打开导航。

## 数据

- SQLite：`data/weekly-review.sqlite3`
- 上传的背景：`data/uploads/`
- 内置背景：`public/backgrounds/`

关闭服务后，复制整个 `data` 文件夹即可备份。恢复时把备份放回同一位置。所有数据都保存在本项目文件夹内。

截止时间使用浏览器所在时区的本地时间，不自动换算时区。服务只监听本机地址。
